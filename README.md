# VOSC Activity-1

## Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript as part of VOSC Activity 1.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Two-player gameplay
- Player X and Player O turns
- Win detection
- Draw detection
- Restart game button
- Simple user interface

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start playing the game.

## How to Play

1. Player X starts the game.
2. Players take turns clicking an empty square.
3. The first player to get three marks in a row wins.
4. If all nine squares are filled without a winner, the game is a draw.
5. Click the **Restart Game** button to start a new game.
